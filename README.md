# StoryCast – An Accessible Media Feature Microsite

## Live Website

Visit the published website here:

**https://cashme8.github.io/storycast/**

## About the Project

StoryCast is a media-focused website created to present stories through video, images, and written content. The goal was to create a modern website where people can explore stories while making the content accessible and easy to follow.

The featured story focuses on Rwanda's journey towards Formula 1, highlighting the country's growing interest in motorsport and its future possibilities.

This project was developed as part of a web design assignment, with a focus on responsive design, accessibility, and using HTML, Sass, and JavaScript to build the website.

## Main Features

- **Homepage:** Introduces StoryCast and highlights the featured story.
- **Video content:** Includes an embedded YouTube video to bring the story to life.
- **Image slideshow:** Displays a series of images related to the featured story.
- **Featured stories:** Presents story cards with images and descriptions.
- **Story page:** Provides more information about the featured media story.
- **About page:** Explains the project and its accessibility approach.
- **Responsive layout:** Adapts the website to different screen sizes.
- **Accessibility features:** Includes semantic HTML, keyboard focus styles, and support for reduced-motion preferences.

## Technologies Used

- **HTML5** – Used to structure the website and its content.
- **Sass (SCSS)** – Used to organise styles into reusable files.
- **CSS3** – Used for layouts, animations, typography, and responsive styling.
- **JavaScript** – Used for interactive features such as the image slideshow.
- **YouTube Embed** – Used to include video content.
- **Git and GitHub** – Used for version control and project hosting.
- **GitHub Pages** – Used to publish the website online.

## Accessibility

Accessibility was an important part of the project. The website uses semantic HTML elements to give the content a clear structure. Keyboard focus styles help users navigate interactive elements, and reduced-motion preferences are considered for users who prefer fewer animations.

The project also uses responsive layouts to help keep the content usable on different devices. Video content should be accompanied by appropriate captions or a transcript where available.

## Running the Project Locally

To view the project on your own computer:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
4. If you edit the Sass files, compile them to update `css/main.css`.
